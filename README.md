# GitDrive 🚀

> Turn your GitHub repositories into your personal, secure, high-speed cloud drive.

GitDrive is a desktop application that transforms GitHub into a personal cloud storage drive with zero server costs, client-side encryption, and seamless file management.

---

## ⚡ 1-Line Installation

You can install the GitDrive desktop application directly from your terminal:

```bash
npx gitdrive-install
```

### Or using native scripts:

#### macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/theabhishekarmagi/GitDesk/main/install.sh | bash
```

#### Windows:
```powershell
irm https://raw.githubusercontent.com/theabhishekarmagi/GitDesk/main/install.ps1 | iex
```

#### Homebrew (macOS):
```bash
brew install --cask theabhishekarmagi/tap/gitdrive
```

---

## ✨ Features
- **Unlimited Storage**: Backed directly by your GitHub account.
- **Client-Side Security**: Hardware-encrypted Personal Access Token stored securely in macOS Keychain / Windows Credential Manager.
- **Drag-and-Drop**: Native OS drag-and-drop support directly into macOS Finder and Windows File Explorer.
- **Version History**: Browse and restore past versions of any uploaded file.
- **Apple Notes Dark Aesthetic**: Sleek, minimalist neutral dark gray interface.
